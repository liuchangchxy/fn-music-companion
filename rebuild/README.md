# 飞牛音乐伴侣 (MusicFlow for fnOS) - 核心管道设计说明

专为飞牛 NAS 设计的高保真无损音乐整理与元数据流水线。

## 核心设计与空间规则

- **零空间 Reflink CoW**：发布过程优先使用 `cp --reflink=auto -p`，利用 Btrfs 文件系统底层写时复制，0 额外物理空间开销。
- **不可变源保护 (Immutable Source)**：原始目录强制只读（`:ro`），原始文件永不移动、删除、改标签或建立破坏性硬链接。
- **零冗余解密隔离**：NCM 在沙盒解密一次后由声纹引擎和发布模块共享复用，杜绝重复解密造成的几十 GB 磁盘 IO 损耗。
- **跨格式声学指纹**：使用 Chromaprint / dupsonic 比对真实音频波形（相似度 >= 0.997），跨 MP3/FLAC 识别相同音轨并优先保留高保真无损格式。
- **受控多源元数据**：MusicBrainz 限流 1 req/s + 候选集上限优化（`searchlimit: 3`）+ 45s 超时自适应熔断；自动获取 LRCLIB 同步滚动双语歌词与 SACAD 超清原版封面。
- **状态持久化**：SQLite 存储全生命周期记录，支持全量秒级复用对齐与增量幂等更新。

## 元数据与去重规则（v6 实机修正）

1. **简繁归一**：国内源（QQ 音乐 Smartbox 联想 + 网易云）按简体收录，检索前统一经
   `to_simplified()` 归一（构建镜像时尝试安装 `zhconv` 获得完整对照表，装不上则回退内置字表），
   因此 `周杰倫《東風破》` 能命中 `周杰伦《东风破》` 的原版歌词与封面；去重比对
   （艺术家 / 曲名分桶）同样做简繁折叠，避免同一首歌因标签繁简不同被保留两份。
2. **同录音去重**：时长容差 `MUSIC_SAFE_DURATION_DELTA=4.5` 秒（精选集/单曲版片头片尾静音差异）；
   比对桶 Key 先剥掉 `(Radio Edit) / (Single Version) / (Remaster)` 等包装附注，时长完全一致时直接视为同一音轨；
   `Live / Acoustic` 等真实不同录音仍保持互斥保护，落入“疑似版本组”由人工确认。
3. **外挂歌词**：WAV/AIFF 无法内嵌歌词，其他容器也可能写入失败 —— 一旦发生，
   国内引擎取回的歌词会写成同名 `.lrc`（随发布一起进入曲库），并跳过无意义的海外 Beets 歌词回退。
4. **文件名兜底**：文件内无标签时，用**原始文件名**（而非带随机后缀的沙盒名）提炼
   `歌手 - 歌名`，再交国内引擎补全艺术家/专辑/封面；仍落在
   `Unknown Artist / Unknown Album` 的曲目会在下次运行时自动重试（飞牛 App 依赖 Artist/Album 建索引）。
5. **品质升级置换**：增量整理时若新到的无损文件优于库中已有有损副本，
   自动发布高保真版本，并将旧副本移入隐藏目录 `.music-archive/`（账本记为 `superseded`），
   曲目位置变化时同样归档旧位置，避免曲库出现两份同名文件。
